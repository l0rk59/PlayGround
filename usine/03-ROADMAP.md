## Phase 1 - PIPELINE MINIMAL (semaines 2-3)
- Bloc 0 opérationnel : Idéateur réel (génération + scoring + sélection)
- Bloc 1 opérationnel : PRD généré + bouton GO
- Bloc 3 minimal : générateur de landing page HTML complète livrable
- Livrable : "surprends-moi" fabrique une mini-page web

## Phase 2 - MULTI-FORMATS (semaines 4-6)
- Design system de l'usine commun à tous les produits
- Fabrique lance : PWA, ebook, template, petit jeu
- Bloc 4 : tests + revue LLM automatiques

## Phase 3 - AUTONOMIE (semaines 7-10)
- Mode autonome : l'usine propose 3 idées par semaine, construit la mieux notée
- Journal d'usine + mémoire des briques réutilisables
- Bloc 6 : boucle d'amélioration des produits existants

## Phase 4 - COMPLÉTUDE (semaines 11+)
- Suffisance : produits mobile PWA installables sur le téléphone
- Export / déploiement à un clic
- Rapport de gestion mensuel des usines
